# Discord Server 設定步驟

這份文件帶你做三件事:

1. 建立自己的 Discord Server(伺服器)
2. 建立給 agent 使用的頻道,並取得 `CHANNEL_ID`
3. 產生邀請連結,讓同組同學加入

> Discord 偶爾會改畫面和用字。下面的按鈕名稱同時寫了中文和英文,如果你的畫面和文件有一點不一樣,找意思相近的按鈕就可以。

建議用**電腦版 Discord**(桌面程式或瀏覽器 `https://discord.com/app`)操作,不要用手機,因為下面的步驟都以電腦畫面為準。

---

## 一、建立自己的 Discord Server

1. 打開 Discord,登入你的帳號。
2. 看畫面**最左邊那一排圓形圖示**(伺服器列表)。拉到最下面,找到一個**綠色的「+」圓形按鈕**(新增伺服器 / Add a Server),點它。
3. 跳出「建立伺服器」視窗,點 **「自己建立」(Create My Own)**。
4. 下一個畫面問你這個伺服器是給誰用的,點 **「與朋友」(For me and my friends)**。
5. 下一個畫面:
   - **伺服器名稱**:輸入例如 `food-photo-agent`(名稱隨你,之後可以改)。
   - 圖片可以不用上傳。
6. 點右下角的 **「建立」(Create)**。

做完之後,你會在最左邊的列表看到新的伺服器圖示,並且自動進入這個伺服器。

---

## 二、開啟「開發者模式」(取得 ID 前一定要先做)

Discord 預設不會顯示頻道和使用者的 ID,要先打開開發者模式,右鍵選單才會出現「複製 ID」。

1. 看畫面**左下角**,你的頭像旁邊有一個**齒輪圖示**(使用者設定 / User Settings),點它。
2. 在左邊選單往下找到 **「進階」(Advanced)**,點它。
3. 找到 **「開發者模式」(Developer Mode)**,把右邊的開關**打開**(變成綠色)。
4. 按右上角的 **ESC** 或 **X** 關閉設定。

---

## 三、建立給 agent 使用的頻道

1. 在你剛建立的伺服器裡,看**左邊第二欄**(頻道列表)。你會看到預設的「文字頻道」分類,底下有一個 `一般`(general)頻道。
2. 把滑鼠移到「**文字頻道**」這幾個字上,右邊會出現一個 **「+」**(建立頻道 / Create Channel),點它。
3. 跳出「建立頻道」視窗:
   - **頻道類型**:選 **「文字」(Text)**。
   - **頻道名稱**:輸入 `food-photo-agent`(Discord 會自動把空格換成減號,字母會變小寫)。
   - **私人頻道**(Private Channel)的開關:**先不要打開**。開了的話,bot 和同學都要另外加權限,第一次設定很容易卡住。
4. 點 **「建立頻道」(Create Channel)**。

---

## 四、取得 CHANNEL_ID

1. 在左邊的頻道列表,找到剛建立的 `food-photo-agent` 頻道。
2. 在這個頻道的名稱上按**滑鼠右鍵**。
3. 在跳出的選單最下面,點 **「複製頻道 ID」(Copy Channel ID)**。
   - 如果看不到這個選項,回到第二段確認「開發者模式」已經打開。
4. 打開記事本(Notepad),按 **Ctrl + V** 貼上。你會看到一串很長的數字,例如 `1234567890123456789`,這就是 `CHANNEL_ID`。
5. 把這串數字暫時存起來(例如記在記事本裡),之後設定程式時會用到。

> `CHANNEL_ID` 只是頻道的編號,不是密碼,貼給同學看沒關係。**bot token 才是不能外流的**,在另一份文件 `docs/discord-bot-setup.md` 有說明。

### 順便取得你自己的使用者 ID

之後 agent 會用「使用者 ID」判斷誰可以使用,所以現在一起取得:

1. 在左下角你自己的頭像或名字上按**滑鼠左鍵**,跳出你的個人小卡。
2. 在小卡上按**滑鼠右鍵**(或點右上角的「⋯」),選 **「複製使用者 ID」(Copy User ID)**。
3. 貼到記事本,標註這是「我的使用者 ID」。

---

## 五、產生邀請連結,讓同組同學加入

1. 在左邊頻道列表,對 `food-photo-agent` 頻道按**滑鼠右鍵**,選 **「邀請用戶」(Invite People)**。
   - 也可以在最左邊列表的伺服器圖示上按右鍵,選「邀請用戶」。
2. 跳出邀請視窗,最下面會有一條連結,長得像 `https://discord.gg/xxxxxxx`。
3. 預設的連結**只有 7 天有效**。如果希望同學之後也能加入:
   - 點視窗下方的 **「編輯邀請連結」(Edit invite link)**(或視窗角落的小齒輪)。
   - **「到期時間」(Expire after)**:選 **「永不」(Never)**,或選你需要的天數。
   - **「使用次數上限」(Max number of uses)**:可以選「無限制」,或限制成同學人數(例如 5 次),比較安全。
   - 點 **「產生新連結」(Generate a New Link)**。
4. 點連結右邊的 **「複製」(Copy)**。
5. 把連結貼給同組同學(用你們原本的通訊軟體,不要貼在公開的地方)。

### 同學怎麼加入

同學收到連結後:點連結 → 選「接受邀請」(Accept Invite) → 登入 Discord(如果還沒登入)。完成後,他們會出現在你的伺服器成員列表。

### 之後想停止邀請

點伺服器名稱旁邊的小箭頭 → **「伺服器設定」(Server Settings)** → **「邀請連結」(Invites)**,找到連結,點右邊的 **X** 就能刪除。

---

## 六、注意事項

- 同學加入伺服器,**不代表他們可以使用 agent**。第一版的設計是只開放白名單內的 Discord 帳號,要讓同學使用,之後還要把他們的使用者 ID 加進白名單(做法相同,請他們用第四段最後的方式取得自己的使用者 ID 給你)。
- `docs/architecture.md` 目前寫的是「只在 DM(私人訊息)回覆」。如果之後要改成在這個頻道裡回覆,架構文件要同步修改,先不要自己改程式。
- 不要把邀請連結貼在公開社群,陌生人加入後會看到你的頻道內容。
